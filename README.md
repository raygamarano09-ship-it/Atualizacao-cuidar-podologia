Documentação do Projeto: Cuidar Podologia
1. Visão Geral do Projeto
O site da Cuidar Podologia é uma interface web moderna, responsiva e focada na conversão de pacientes para uma clínica especializada em saúde dos pés. O projeto prioriza a experiência do usuário (UX), um design acolhedor com identidade visual alinhada à área da saúde, e fácil acesso aos canais de contato e agendamento via WhatsApp.

4. Padrões Técnicos e Boas Práticas
Acessibilidade (WCAG): O código de estilos (style.css) utiliza variáveis customizadas para paletas de cores e mantém um contraste rigoroso de texto (proporção mínima de 4.5:1), garantindo legibilidade para todos os públicos.

Responsividade: Layout adaptado por meio de CSS Flexbox e Media Queries, proporcionando uma navegação perfeita tanto em computadores quanto em celulares e tablets.

Controle de Versão (Git & GitHub): O projeto é versionado e sincronizado via Git, garantindo histórico de alterações limpo e integração contínua com plataformas de hospedagem (como Vercel/Netlify).
